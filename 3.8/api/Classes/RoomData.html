Room Data

Class Details​

Defined in: Public/RoomData.h
Hierarchy: Object → Data Asset → Primary Data Asset → Room Data
Exposed in blueprint as: Blueprint Base Class | Variable Type

Description​

Static data shared by multiple room instances.
This data is used to define the room's properties and the room level to spawn.
